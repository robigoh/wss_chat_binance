# Binance P2P Chat Bot

Automated chat response bot for Binance P2P merchants.

## Features
- Auto-reply to common buyer messages
- Daily/30-day buy limits per customer
- Telegram notifications
- Automatic stablecoin conversion (USDC, FDUSD → USDT)

## Setup
1. Clone repo
2. Install: `pip install -r requirements.txt`
3. Create PostgreSQL database
4. Generate RSA key pair
5. Configure environment variables
6. Run: `python wss_chat.py`
